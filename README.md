### 1. [CloudShield](https://github.com/mmmphyun/aleph-project)
**클라우드 위협 탐지부터 자동 차단·Slack 알림까지 10초 이내 대응을 목표로 하는 SecOps 파이프라인 (팀 프로젝트 · 개발 중)**

- **담당**: 네트워크 담당으로 SSH 정상 연결·Hydra 인증 실패 재현 환경, tcpdump 패킷 캡처 스크립트, Curl/Gobuster 기반 Web 디렉터리 스캔 시뮬레이터와 pytest 모의 테스트 구현
- **문제**: 탐지 조건을 검증할 재현 가능한 공격 트래픽과 정상 기준선이 필요했고, 암호화된 SSH 패킷만으로는 인증 실패를 판별하기 어려웠음. 실험 과정에서는 tcpdump 권한 강하 이후 프로세스 제어 오류와 캡처 대기 시간 부족도 발생
- **해결**: Docker 내부 bridge에 서버·클라이언트를 격리하고 실행 시간·동시성·대상을 제한. PCAP의 TCP 연결 흐름과 서버 인증 로그를 함께 분석하고, 필요한 capability와 캡처 대기 시간을 보완한 뒤 모의 테스트로 검증
- **검증 성과**: 정상 SSH 연결의 39패킷·1개 TCP 스트림을 기준선으로 확보. Hydra 실험에서 78패킷·3개 스트림·인증 실패 7건·인증 성공 0건을 확인하고 SYN/ACK, FIN/RST, 재전송 여부를 비교 분석
- **주요 기술**: Python, Bash, Docker, OpenSSH, Hydra, tcpdump, TShark, Curl, Gobuster, pytest
